# Kino Design System

## Core Intent

Design with a quiet editorial system: spacious, tactile, lightly handmade, and precise. The style should feel like a personal portfolio or art-directed design system, not a generic SaaS interface or loud marketing page.

Use the source board at `assets/kino-design-system-reference.png` as the visual reference. Read `references/visual-language.md` when producing concrete UI, layout, deck, brand, or image-generation work.

## Default Workflow

1. Treat this style as the default design direction unless the user explicitly asks for another style.
2. Start with a white or soft neutral canvas, thin divider lines, generous margins, and restrained contrast.
3. Use a serif display voice for headlines and a clean sans voice for labels, metadata, captions, buttons, and body support.
4. Bring color through textured painterly fields, brush bands, underlines, image overlays, or small accents instead of flat color blocks everywhere.
5. Keep components sparse: framed cards, narrow navigation, minimal icon buttons, thin rules, modular image grids, and editorial section numbering.
6. Before finalizing, check that the result is calm, airy, tactile, and structured. If it reads as glossy, neon, corporate, heavy, or template-like, revise toward the reference.

## Must Preserve

- Lots of negative space and visible grid discipline.
- Thin black or gray hairlines, never heavy borders.
- Large serif headlines with quiet confidence.
- Soft blue, green, yellow, lavender, and neutral texture accents.
- Minimal icons with simple line strokes.
- Small uppercase section labels and numbers.
- Brush-like strokes for buttons, highlights, active states, or hero texture.

## Avoid

- Dark mode as the default.
- Dense gradients, glassmorphism, glowing effects, bokeh blobs, or decorative orbs.
- Rounded pill-heavy UI unless the product context absolutely requires it.
- Oversized marketing-card composition.
- Loud saturated palettes, especially dominant purple-blue gradients.
- Generic stock-photo treatment with dark overlays.
- Heavy shadows, thick borders, and overfilled sections.
