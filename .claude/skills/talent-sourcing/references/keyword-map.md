# Keyword Map

先按技术主题选词，再按渠道翻译成中英文变体。每次至少同时准备：

- 核心词
- 技术词
- 证据词
- 排除词

## 1. RL / Post-training

核心词：

- 强化学习
- RL
- RLHF
- 对齐
- 后训练

技术词：

- PPO
- DPO
- reward model
- preference model
- policy optimization
- SFT
- evaluation
- policy gradient

证据词：

- reward
- preference data
- alignment
- judge model
- offline eval
- online eval

排除词：

- 推荐系统优化
- 广告投放
- 量化交易

## 2. Agent

核心词：

- Agent
- AI Agent
- 智能体
- Agentic

技术词：

- tool use
- function calling
- planning
- workflow
- memory
- multi-agent
- browser agent
- computer use

证据词：

- eval
- success rate
- task completion
- trajectory
- orchestration
- tool routing

排除词：

- 纯 prompt
- 纯运营
- 纯产品方案

## 3. Agent + RL 交叉

优先组合词：

- Agent + RLHF
- Agent + eval
- tool use + reward
- planning + policy
- multi-agent + optimization
- workflow + reinforcement learning

适合英文渠道的 title 扩展：

- Research Scientist
- Applied Scientist
- Research Engineer
- ML Engineer
- Staff ML Engineer
- Agent Engineer
- Post-training Engineer

不建议单独使用的宽泛词：

- 算法工程师
- AI 工程师
- 大模型

这些词只能作为补充召回，不能作为主轮次唯一关键词。

## 4. 黑湖场景业务词

当岗位带工业/制造业语境时，附加以下词：

- 决策系统
- 调度优化
- 生产计划
- 异常分析
- 根因分析
- 运营优化
- knowledge + action
- decision support
- enterprise copilot

这些词不是硬门槛，但能帮助区分“会做 demo”和“能做业务闭环”的人。
