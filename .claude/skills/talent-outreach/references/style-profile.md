## Global Tone

```yaml
address:
  chinese_technical: "老师" + "您"
  chinese_peer: "你"              # 同龄人或年轻技术人
  chinese_warm: "咱们"            # 建立亲近感时使用（样本2中出现的模式）
  chinese_unknown: "你好"
  english_technical: first_name directly
  english_unknown: "Hi {first_name}"

hook:
  pattern: "{具体事实/数字} + {为什么这个人会关心} + {可以一起做什么}"
  from_samples: |
    样本1结构：先讲优势 → 再讲文化 → CTA
    样本2结构：公司背景 → 产品 → 为什么做AI → 具体项目深度展开 → 价值论证 → CTA
    共同点：不夸对方，而是展示自己值得对方花时间读

length:
  email_longform: 300-800 chars  # 初次触达，可以长但要干货密集
  email_short: 3-5 sentences     # 跟进或已知兴趣
  short_channel: 1-3 sentences

voice:
  primary:
    - "我们" > "黑湖" > "公司" — 团队感优先
    - 数字就是说服力 — "34000+" 不是 "很多"
    - 鲜活细节 > 抽象概括 — "【农夫山泉】【蒙牛】【蜜雪冰城】" 不是 "头部客户"
  secondary:
    - 括号注释是风格特征 — 用 `（）` 补充背景、加幽默（"hhh"）、自嘲
    - 允许口语化 — "别看小"、"最不济"、"hhh"
    - 可以深入展开一个具体案例 — 让别人真正理解你在做什么
    - "不是雄心壮志做大而全" → 务实定位，对务实型候选人有效
  short_channel:
    - 一个 vision 句子开路 — "我们在用AI Agent实现一件事：..."
    - 否定式对比建立张力 — "不是A，不是B，是真的C"
    - 三个信号速射 — 盈利/融资/汇报线，一短句说完，不给啰嗦空间
    - CTA 极端简短 — "方便聊聊吗？" 四个字

forbidden:
  - recruiter_jargon: "诚邀加入"、"看机会"、"您的能力很匹配"
  - corporate_pitch: "行业领先"、"Y轮融资"、"改变世界"
  - fake_urgency: "机会难得"、"急招"、"HC有限"
  - fake_personal: 不要假装看过对方的工作但实际没看过
  - empty_claims: 不用形容词替代事实（"非常厉害"→ 用具体数字或例子）

call_to_action:
  primary: "欢迎加微信17712659049，随时交流"
  soft: "可能咱们工作比较繁忙，不一定有时间能及时看完/回复，没关系，等咱们有空就行"
  alternate: "方便聊聊吗"、"期待有机会交流"
  avoid: "面试"、"发简历"、"走流程"、"您是否考虑"
```

## Channel-Specific Adaptations

```yaml
email:
  subject: "{具体话题/项目} — {来自谁}"
  signature: true
  follow_up_after_days: 5-7
```

## Training Samples

```yaml
samples:
  - channel: "通用/企业介绍"
    text_preview: |
      首先，黑湖是一家2016年成立的工业科技的独角兽企业...
      1.亚太区域第一的多模态数据湖...
      2.行业Know-How和真实场景...
      3.强变现能力，200-300人销售团队...
      其次...80%以上00后...鼓励跨角色...AI-native...
      欢迎加微信17712659049，随时交流！
    structure: "先说优势(3点) → 再说文化(3点) → CTA"
    extracted:
      - "首先/其次" 分块结构
      - 数字密集（2016/4万+/200-300/80%/00后/1-3万）
      - "我们" 语调
      - 直接给联系方式

  - channel: "短消息/快速触达"
    text_preview: |
      我们在用AI Agent实现一件事：让想象能在物理世界里被造出来。
      不是渲染图，不是概念视频，是真的能拿在手上的产品。
      公司已盈利，4月刚融了近10亿D轮，核心团队直接汇报CEO。
      方便聊聊吗？
    structure: "vision宣言 → 否定式对比 → 三信号速射(盈利/融资/汇报线) → 四字CTA"
    extracted:
      - vision-first: 一个句子说清楚使命，不铺垫不解释
      - 否定式张力: "不是A，不是B，是真的C" — 排除抽象、锚定真实
      - 速射信号: 三个硬事实在一个短句里（盈利、D轮、汇报CEO），不拖沓
      - 极端简短CTA: 四个字"方便聊聊吗？"
      - 总长~80字，适合BOSS/脉脉/即刻等短渠道
      - 没有任何公司自我介绍 — 当vision本身就足够说明"我们是谁"时，不需要解释

  - channel: "深度邮件/项目介绍"
    text_preview: |
      黑湖是一家2016年成立的工业科技企业（工业Saas方向），C轮融资近5亿...
      两款产品：【黑湖智造】面向中大KA（农夫山泉/蒙牛/蜜雪冰城），
      【黑湖小工单】面向中小（20-100人，占中国制造业80%+，二八法则hhh）...
      34000+家客户，市占率52.7%，行业第一，24年11月起盈利。
      基于以上，我们有了做行业大模型的基础（Know How、数据、Money）...
      "AI老师傅"项目：订单驱动型工厂 → 老师傅判断(可行性/报价/排产/CAD→图纸)
      → 全部可被AI Agent辅助或执行...
      老师傅年收入30-40万（最高200万），50%+工厂雇不起→丧失订单选择权→代工厂...
      雇得起的工厂，产品让数据可继承，不再是口口相传...
      走进工厂，探索大模型能力，真正帮助他们...
      可能咱们工作比较繁忙，不一定有时间能及时看完/回复，没关系，等咱们有空就行。
    structure: "公司背景 → 产品 → 为什么做AI → 具体项目深度展开(场景→痛点→价值) → CTA"
    extracted:
      - 括号注释是签名特征（补充背景/加幽默/自嘲）
      - "【】" 用于具名客户
      - "咱们" 建立亲近
      - 一个具体案例深度展开（AI老师傅）比十个泛泛而谈有效
      - 超低压CTA："可能繁忙...没关系...等有空"
      - "hhh" 可以用但适度
      - "不是雄心壮志做大而全" → 务实定位
      - 场景描述极其具体（输入→输出→验证方式），证明你真的理解问题
```

## Notes

- 三种格式已覆盖：短消息（~80字vision-first）、结构长文（先优势再文化）、深度邮件（一个案例深挖）。针对不同渠道和候选人类型，生成时自动选择最匹配的格式。
- 样本2的"AI老师傅"案例是深度邮件的最佳钩子 — Agent/多模态/工业AI候选人尤其有效。
- 样本3的vision+否定式对比+速射信号是短渠道模板 — BOSS/脉脉/即刻直接套用。
- 中英文混合样本后续补充。如果需要对海外候选人做英文触达，请提供英文样本。
