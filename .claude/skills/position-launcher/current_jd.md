# 招聘实习生（招聘交付方向）

## 关于我们

黑湖科技成立于 2016 年，是一家专注工业领域的科技公司，用 SaaS 产品帮助制造业完成从计划到执行的数字化升级。目前服务超过 37,000 家工厂，客户覆盖汽车、快消、电子、新能源等多个行业，在工业 SaaS 领域处于市场领先位置。

随着业务快速扩张，团队招聘需求持续增加。我们正在用 AI 重新构建招聘工作流——多渠道 Agent 协同、数据驱动决策——让招聘从"靠人海"走向"靠判断"。

## 岗位职责

- 参与招聘交付全流程：从岗位需求理解、人才画像拆解，到候选人寻源、触达、面试跟进、Offer 落地
- 围绕招聘目标开展多渠道挖猎：在 BOSS直聘、脉脉、猎聘等平台进行候选人搜索与定向 mapping
- 负责候选人触达与沟通，基于候选人背景做个性化触达，而非批量群发
- 跟进面试安排、候选人反馈、流程推进，保证招聘进度
- 将招聘过程数据沉淀至飞书多维表格，支持招聘结果的可追踪与复盘
- 参与招聘策略复盘，与团队一起分析推进瓶颈、迭代挖猎方向

## 任职要求

- 在校生或应届毕业生均可
- 每周可到岗 4 天及以上，能持续 3 个月以上
- 专业不限，欢迎跨专业同学
- 对招聘 / 人力资源方向有兴趣
- 具备较强的逻辑思维与沟通能力，做事细致、有责任心
- 自驱力强，能在不确定的任务中主动定义下一步行动

## 加分项

- 有招聘 / HR / 猎头方向实习经验
- 日常高频使用 AI 工具（Claude、ChatGPT 等），对 AI Agent 与工作流自动化有体感
- 对工业 / 制造业方向有兴趣

## 你将获得

- 深入参与真实的招聘交付过程，不是模拟，是真实在招的岗位、真实的候选人
- 接触一套以 AI 为核心重构的招聘工作流：多渠道 Agent 编排、数据驱动决策、定向挖猎方法论
- 完整的带教体系，覆盖招聘判断、挖猎颗粒度、业务需求沟通等核心能力
- 表现优异者有转正机会
