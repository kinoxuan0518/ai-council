## 脉脉版

**职位名称**: 资深AI产品经理 — 工业Multi-Agent决策系统

### About This Role

工业 AI 正在从"辅助建议"进化到"自主决策"——我们相信下一个拐点是 Multi-Agent 系统在真实工业场景中的落地。这不是一个锦上添花的 AI 功能，而是一个从 0 开始、重新定义工业决策范式的产品。

我们在找一个做过 Agent 产品的 PM，来主导这个方向。行业经验不重要——我们需要的是你对 Agent 的深度理解和产品创造力。

### What You'll Do

- 从产品定义到 MVP 落地，全程主导一个工业 Multi-Agent 决策系统
- 定义 Agent 的边界、能力与协作机制——哪些决策由单个 Agent 完成，哪些需要多 Agent 协同
- 建立 Agent 评估体系：决策正确率、可控性、异常处理、人机协作模式
- 推动 PMF：从工业场景切入，找到第一个愿意付费的客户

### What We're Looking For

- 5-6 年产品经验，其中必须有 AI Agent 产品的实际经验
- 深度理解 Agent 架构：tool-use / task orchestration / agent communication / memory
- 有 0→1 经验，在模糊中定义产品方向
- 能和算法团队深度对话
- 产品直觉好，推动力强

### Why Join

- **定义权**: 0→1 创造，不是接盘
- **决策链**: 直接向 CEO/CTO 汇报
- **赛道**: 工业 Multi-Agent 是巨大蓝海
- **回报**: 薪资开放，看价值不看天花板

### Bonus

来自头部 AI 创业公司或大厂核心 AI 团队；有 Multi-Agent 或自主决策产品经验；toB 经验；工业背景（非必须）。

**技术栈关键词**: AI Agent · Multi-Agent · LLM · RAG · Tool-use · Task Orchestration · 工业AI
