# 信息源检索指南

## 一级来源：政府/官方文件（最高可信度）

### 工商信息
- **企查查**: `https://www.qcc.com` — 公司注册、法人、股东、注册资本、经营范围、社保人数
- **天眼查**: `https://www.tianyancha.com` — 同上，补充司法风险、行政处罚
- **搜索策略**: 搜索候选人姓名 + "法定代表人"/"股东"/"董事"
- **价值**: 发现候选人名下的公司（在职创业信号）、股权关系、关联企业

### 职称与资格
- **各省市人社局官网**: 职称评审公示名单（通常PDF格式）
- **搜索策略**: "候选人姓名 + 职称评审" / "候选人姓名 + 工程师"
- **价值**: 验证技术资质、确认某段经历的真实性（评审申报单位）

### 专利与知识产权
- **国家知识产权局**: `https://www.cnipa.gov.cn`
- **搜索策略**: 候选人姓名作为发明人搜索
- **价值**: 技术深度的客观证据

### 学术论文
- **中国知网(CNKI)**: `https://www.cnki.net`
- **Google Scholar**: `https://scholar.google.com`
- **万方数据**: `https://www.wanfangdata.com.cn`
- **搜索策略**: 候选人姓名 + 单位名称
- **价值**: 署名单位验证经历、研究方向验证技术能力

## 二级来源：企业官方渠道（高可信度）

### 公司官网
- 新闻稿/动态：搜索候选人姓名出现
- 团队介绍页：验证头衔和角色
- 产品页面：理解候选人所在业务的真实状态
- **搜索策略**: `site:company-domain.com 候选人姓名`

### 企业公众号/官方社媒
- 微信公众号搜索（通过搜狗微信搜索 `https://weixin.sogou.com`）
- 企业官方知乎/微博账号

## 三级来源：行业/招聘/学术（中等可信度）

### 招聘平台
- **猎聘**: `https://www.liepin.com` — 以"寇先生·制造部副总监"形式暴露真实头衔
- **Boss直聘**: `https://www.zhipin.com`
- **LinkedIn**: 中英文名搜索
- **价值**: 真实头衔验证（招聘平台头衔通常比简历更准确）、招聘行为反映其负责范围

### 行业会议与活动
- 搜索策略: "候选人姓名 + 峰会/论坛/大会/演讲"
- **价值**: 对外露出的头衔、演讲主题反映核心能力主张

### 行业协会
- 各行业学会/协会官网
- 搜索策略: "候选人姓名 + 学会/协会/委员会"

### 知乎/爆料平台
- 搜索前雇主的员工评价、爆料
- **价值**: 了解候选人前雇主的真实经营状况

## 四级来源：数字足迹（辅助验证）

### 技术平台
- **GitHub**: 邮箱关联检测、用户名搜索、公开仓库
- **CSDN/掘金/SegmentFault**: 技术博客
- **Stack Overflow**: 技术问答

### 社交媒体
- **知乎**: 专业观点输出
- **微博**: 个人动态
- **脉脉**: 职场信息
- **小红书/抖音/B站**: 内容输出
- **LinkedIn**: 职业信息
- **Twitter/X**: 国际化信号

### 邮箱关联检测
- 使用候选人邮箱检测在各平台的注册状态
- 有GitHub注册但无公开仓库 → 工具性使用，非活跃开发者
- 无任何社交媒体注册 → "数字隐身"型，需注意

## 搜索方法论

### 多关键词组合
```
第一轮: "候选人姓名" (中文)
第二轮: "候选人姓名 + 公司名称"
第三轮: "候选人姓名 + 行业关键词"（如"智能制造"、"AI"）
第四轮: "候选人英文名" (如有)
第五轮: "候选人邮箱前缀" 在各平台搜索
```

### 反向搜索
```
从公司出发: 搜索公司官网、新闻，寻找候选人被提及
从项目出发: 搜索项目名称、产品名称，寻找候选人关联
从行业出发: 搜索行业会议参会名单
```

### 同名排除原则
1. 地理位置是否匹配（城市、省份）
2. 行业/领域是否匹配
3. 年龄段是否合理
4. 工作单位是否交叉验证
5. 无法确认时标注"可能同名不同人"

## 信息可靠性评级标准

| 等级 | 标准 | 示例 |
| --- | --- | --- |
| ★★★★★ | 政府文件或多个独立来源一致确认 | 工商登记法人、职称评审名单 |
| ★★★★☆ | 企业官方渠道确认 + 一个独立来源佐证 | 公司新闻稿提及 + 招聘平台头衔一致 |
| ★★★☆☆ | 单一可信来源确认 | 仅公司官网提及 |
| ★★☆☆☆ | 仅候选人自述，搜索未找到佐证 | 简历写在某大厂工作，但搜索为空 |
| ★☆☆☆☆ | 存在矛盾信息 | 简历时间线与公开报道冲突 |
