# AI Council

Claude Code Skills for recruitment intelligence and candidate research.

## Skills

### candidate-intelligence

候选人竞调 Skill — 基于公开信息的候选人深度调研与验证工具。

结合情报式信息获取（穷举公开信源、交叉验证、标注置信度）与决策支持式分析（面评×简历×外部信息三角验证、行业框架定位、可执行验证方案），输出一份对招聘决策直接有用的报告。

**核心能力**：
- 多源信息搜索与交叉验证（工商信息、招聘平台、学术数据库、数字足迹）
- 雇主公司深度画像
- 时间线矛盾与头衔差异识别
- ISA-95/MOM 等行业框架定位
- 个人性格与行为风格画像
- 可执行的后续验证方案（事实核验清单 + 能力核验考题）

**使用方式**：作为 [Claude Code](https://docs.anthropic.com/en/docs/claude-code) 的自定义 Skill 使用。
